Documentation

One API for Solana token extensions.

{{NAME}} reads what a Solana token is allowed to do to the people who hold it. It reads the chain and returns data or unsigned transactions, and its launchpad creates new tokens with the label already known. It never holds keys and never signs.

The Token-2022 program lets a mint carry extensions: a transfer hook that runs a program inside every transfer, a transfer fee, a permanent delegate that can move anyone's balance, accounts frozen by default, a pause switch. Together with the classic mint and freeze authorities, these decide what holding a token really means. {{NAME}} decodes them for any mint, keeps an index of thousands of traded tokens, tracks the transfer-hook programs behind them, and attaches the warnings to every quote.

Quickstart

Open, keyless, plain JSON, open CORS. The base URL is .




Decode API


GET/v1/tokens/:mintEvery power the mint holds, with details (hook program, fee rate, delegate, authorities), capability notes, a risk level, and market data.
GET/v1/powersThe catalogue of powers and their levels.


Works for any mint on either token program, indexed or not: it reads the mint account live. details.transferHookSlot appears when no hook program is set but an authority could attach one later.



Token index


GET/v1/tokensIndexed tokens. power (one or more, comma-separated, e.g. transferHook,transferFee), hook (a hook program), program (token-2022 or spl-token), verified, q, sort (mcap, liquidity, volume, holders, recent), limit, offset.
GET/v1/censusHow many decoded tokens hold each power, and their combined market cap.
GET/v1/statsIndex totals and sync state.


The index takes its token list from Jupiter (verified tokens, the most traded, trending and newest) and decodes each mint from the chain, refreshing every few hours. Market data comes from Jupiter; the powers always come from the mint account.



Hook programs


GET/v1/hooksTransfer-hook programs ranked by how many indexed tokens run them.
GET/v1/hooks/:programOne program: whether it is deployed, its upgrade authority, and the tokens that use it.


A transfer hook is only as fixed as its program. If the program has an upgrade authority, the rules of every transfer can be replaced after you buy. {{NAME}} reads the program's data account to tell you.



Token check


GET /v1/tokens/:mint/check combines the mint's powers, the hook program's upgradeability, and (with amount in SOL) a live quote into a risk level with plain-English reasons. Show the reasons to your users, not only the level.



Quote & swap


GETPOST/v1/quoteinputMint, outputMint, amount (decimal, input units), slippageBps. Routed by Jupiter; the response carries the warnings for both tokens.
POST/v1/swap/buildThe same fields plus user. Returns an unsigned versioned transaction in base64 for the wallet to sign.



Launchpad


One transaction creates a Token-2022 mint with its extensions, writes its name, symbol and link into the mint, opens your token account, mints the whole supply to it, and removes the mint authority. Nothing is deployed and no program stands between you and the token program: the instructions go straight to System, Token-2022 and the Associated Token program.




GET/v1/launch/optionsThe presets (clean, fee, hooked) and the limits.


POST/v1/launch/buildcreator, mint, name, symbol, then the rules: decimals (6), supply (1,000,000,000), feeBps (0 to 1000), maxFee, lockFee (true), hookProgram, lockHook (true), keepMintAuthority (false), freezeAuthority (false), lockMetadata (false). Metadata: your own uri, or description, image, website, x and this node serves the JSON.


POST/v1/launch/sendmint and the signed transaction (base64). Both signatures are verified here, then the transaction is passed to Solana.


GET/v1/launch/:mintOne launch read back from the chain: built, sent, live, failed or expired, with the decoded powers once it is live.


GET/v1/launch/listLaunches confirmed on chain, newest first. creator, limit, offset.


GET/v1/launch/meta/:mintThe metadata JSON a launched mint points at.


GET/v1/launch/fees/:mintTransfer fees withheld for the fee authority, on the mint and on holder accounts. Optional accounts (comma-separated token accounts) to name where to look.


POST/v1/launch/claimmint, authority. An unsigned transaction that withdraws the withheld fees to the authority's own token account.


Two signatures. mint is a fresh public key you generate; its secret never leaves you. The build response is an unsigned legacy transaction: sign it with the creator wallet first, then with the mint key, and post it to /v1/launch/send. On the launch page the mint key is made in your browser tab and used once.


Checked before you sign. Every build is run against the chain as it stands. simulation.ok says whether Solana would accept it, rent.total is what it would cost your wallet, and preview is the label decoded from the mint the chain would create: the same powers and risk level /v1/tokens/:mint will return once it exists.


What each rule does to the label. A transfer fee reads as medium risk; with lockFee the note says the rate can no longer be changed. A transfer hook reads as high risk, and the build tells you if your hook program is still upgradeable. Keeping the mint or freeze authority adds those powers. A fixed-supply token with no fee and no hook reads as low risk.


Fees. {{NAME}} takes no launch fee and no share of your transfer fee. You pay Solana's rent for the mint and your token account, about 0.006 SOL, plus the network fee. Transfer fees accumulate on the receiving accounts; you are the withdraw authority and claim them whenever you like.


Liquidity. The whole supply lands in your wallet. Open a pool with it on the venue you prefer; check that the venue supports the extensions you chose, since some pools do not accept tokens with a transfer hook.



Agent tools (MCP)


The endpoint  speaks MCP over streamable HTTP (JSON-RPC on POST, JSON responses, no sessions). Thirteen tools, none of which signs or sends: decode_token, check_token, list_tokens, list_hook_programs, inspect_hook_program, quote, build_swap, list_powers, get_stats, build_launch, list_launches, get_token_fees, build_fee_claim.

Risk levels


highA permanent delegate, an active transfer hook, a non-transferable token, accounts frozen by default, or a pause switch: someone can move, block or stop your tokens.
mediumA transfer fee, a freeze authority or a mint authority.
lowNone of the above.


A level describes what the token is able to do, not what its issuer will do. Regulated stablecoins and tokenized stocks often hold high-level powers on purpose.



Errors


Every error has the same shape: { "error": { "code", "message" } }.


400 bad_requestMissing or malformed input.
404 not_foundUnknown route, or the address is not a token mint.
403 not_authorityOnly the token's withdraw authority can claim its fees.
422 no_routeJupiter has no route for that pair or size.
422 bad_hookThe hook program address is not an executable program.
422 rpc_rejectedSolana turned the transaction down; the message says why.
502 upstream_errorThe Solana RPC or Jupiter did not answer.
